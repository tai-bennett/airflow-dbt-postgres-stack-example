#+TITLE: Data science stack (airflow, dbt, postgres)
This project is meant as a learning example for a data science stack. Specifically, upgrading from the local sqlite3 setup to a proper server with orchestration.

* Stack Overview
** Containerization
There are three main containers in this stack
1. *Airflow + dbt* handles orchestration and scheduling. Here, dbt is used as a tool instead of a service so transforms are also handled in this container.
2. *Postgres* is the database
3. *ML* is a python/pytorch container that handles the model training and saving.
4. *Inference* is a small service (for now) that provides a simple API for model inference.
* Prerequisites
** Docker Engine
Docker engine was installed using [[https://docs.docker.com/engine/install/ubuntu/#install-using-the-repository][this tutorial]].
*** Arch
On arch, we have to do this more manually. We start with
#+BEGIN_SRC bash
sudo pacman -S docker docker-compose
#+END_SRC
Then we have to start the docker daemon. We do this by configuring that the docker daemon start at startup with
#+BEGIN_SRC bash
# sudo systemctl start docker.service # this does onetime docker daemon 
sudo systemctl enable docker.service # this configures for running on startup
#+END_SRC

We could end here, but then we'd have to use sudo everytime we used docker. To avoid this, we can add the current user to an exception using usermod.
#+BEGIN_SRC bash
sudo usermod -aG docker $USER
#+END_SRC

More info can be found at [[https://itsfoss.com/install-docker-arch-linux][here]]
